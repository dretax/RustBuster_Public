RustBuster & Fougerite

For more than a decade, since 2014, RustBuster and Fougerite have been the pioneers of Rust Legacy modding, providing basic anti-cheat protection alongside excellent client and server modding opportunities. Both projects are made by DreTaX and are completely free, driving an open-source community that others have often drawn ideas from. With our growing ecosystem, we are now more than competitive with anything else available for Rust Legacy.

Fougerite is the server-side modding platform, while RustBuster is the client-side anti-cheat and modding platform, together forming one complete ecosystem for Rust Legacy.

The RustBuster client has been transitioned from x86 (32-bit) to a native x64 (64-bit) build, bringing better performance, stability and headroom for future features.

Getting started

Install in under a minute

Download the latest release, extract the zip anywhere you like and start the launcher from the new folder.

Start Steam first and keep it running. RustBuster needs Steam open in the background to launch the game.

The ecosystem

Server-side

Fougerite

The server-side modding platform for Rust Legacy, giving server owners a full plugin API to shape gameplay, build custom game modes and manage their community.
